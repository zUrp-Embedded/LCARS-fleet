# Registre

**Statut** : ecrit par le systeme — ne pas editer a la main

Cet arbre est le **registre** que le runtime tient sur le travail : les ordres de mission remis aux
agents, les verdicts rendus, la provenance de ce qui a ete livre.

Il n'est monte en ecriture pour aucun agent producteur, et c'est le point : un acteur capable de
reecrire ce qu'on lui a demande et ce qu'on a juge de son travail n'est plus jugeable.

Vous pouvez le lire. Ne l'ecrivez pas.
