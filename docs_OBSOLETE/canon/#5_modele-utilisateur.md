# Modèle utilisateur — LCARS actuel

**Date** : 2026-03-30
**Dernière révision** : 2026-03-30
**Statut** : référence extensive
**Référencé par** : canon/README.md
**Dérivé de** : design-history/#8_user-profile.md

> LCARS traite le profil utilisateur comme un paramètre de travail réel. Le but n'est pas de “personnaliser pour faire joli”, mais d'ajuster le niveau de détail et le mode d'échange sans perdre la netteté technique.

---

## 1. Deux couches distinctes

LCARS distingue :
- le profil technique
- le profil psychologique

Le premier règle surtout :
- ce qu'on peut supposer acquis
- le niveau de détail utile
- les domaines où l'explication est nécessaire ou superflue

Le second règle surtout :
- le ton
- la densité
- la tolérance à la répétition
- la manière de poser une question bloquante

---

## 2. Ne pas inférer l'un depuis l'autre

Expertise et style ne sont pas corrélés de façon fiable.

Pourquoi :
- un expert peut vouloir des messages très courts
- un débutant peut très bien préférer un ton sec
- mélanger les deux produit vite des contresens de communication

---

## 3. Le profil n'est pas un gadget relationnel

Dans LCARS, le profil sert à éviter :
- la sur-explication humiliante
- la sous-explication opaque
- les questions inutiles
- le bruit conversationnel

Pourquoi :
- l'efficience de travail dépend aussi de la forme de l'échange

---

## 4. Le standard compte autant que le sur-mesure

LCARS garde un profil standard utilisable pour un onboarding neutre.

Pourquoi :
- un système transférable doit rester utilisable sans profil artisanal pré-écrit
- le standard sert de point de départ propre avant personnalisation

---

## 5. Le profil doit rester sobre et utile

Un bon profil utilisateur :
- aide à mieux travailler
- reste lisible
- évite les fictions psychologiques inutiles

Un mauvais profil :
- psychologise trop
- fige des impressions locales
- devient une prose décorative sans impact opérationnel

---

## 6. Pourquoi cette couche existe encore

LCARS garde ce modèle parce que :
- la précision technique ne suffit pas à elle seule
- la mauvaise forme de réponse peut coûter autant que le mauvais fond
- la transmission à un autre humain doit rester possible sans dépendre du “feeling” d'un agent
