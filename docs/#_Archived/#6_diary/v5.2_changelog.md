## Fichiers modifiés

### regles.md — 3 modifications

**1. GO-0 : ajout corollaire escalade universelle** (zone grise A/ — règle mère manquante)

Ajout après le corollaire "pattern interdit" :
> Corollaire — escalade universelle : si un comportement n'est pas couvert par une règle explicite, l'agent escalade vers l'user immédiatement. Zéro inférence. Zéro exception. Aucun contexte ne suspend cette règle — ni urgence, ni frontier, ni correction d'erreur.

**2. GO-1 corollaire : cas "plusieurs issues"** (zone grise B/1)

Ajout après "les règles laissent une issue → l'agent exécute" :
> Si les règles laissent plusieurs issues ou aucune issue → escalade (corollaire GO-0). Jamais de choix arbitraire.

**3. Règles comportementales : "décisions bornées par les règles"** (zone grise B/2)

Ajout : "Cas non couvert par les règles → escalade user (GO-0 escalade universelle)."

**4. Frontier** (alignement)

"signal d'escalade L4" remplacé par "escalade user (corollaire GO-0 escalade universelle)" — alignement avec la règle mère.
