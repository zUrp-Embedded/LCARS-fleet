**Date** : 2026-03-30
**Dernière révision** : 2026-03-30
**Statut** : index canonique extensif
**Référencé par** : #00_index.md

> Cette base n'est ni le diary, ni la doc opératoire courte. Elle sert à exposer les concepts structurants de LCARS tels qu'ils sont vrais aujourd'hui, sans embarquer tout l'historique de leur apparition.

---

## Rôle

La base canonique extensive sert à :
- présenter les principes et structures actuels de LCARS
- garder le pourquoi du système actuel
- éviter de relire tout `design-history/` pour reconstruire l'intention

Elle ne sert pas à :
- raconter la chronologie complète du projet
- faire doublon avec les man-pages runtime
- remplacer les guides opératoires courts

---

## Sources

Le matériau de cette base vient principalement de :
- `docs/design-history/`
- `docs/#6_diary/`
- la doc vivante actuelle

La règle est simple :
- l'historique reste dans le diary ou `design-history/`
- ici, on ne garde que la forme stabilisée du système
